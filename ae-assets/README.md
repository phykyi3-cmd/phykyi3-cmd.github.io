## ၂။ After Effects တွင် ထည့်သွင်းအသုံးပြုနည်း (Installation Guide)

### နည်းလမ်း (၁) - Mac တွင် ၁ စက္ကန့်အတွင်း အလိုအလျောက် ထည့်သွင်းခြင်း (Recommended)
ဤ Folder ထဲရှိ `install_to_ae.sh` Script ကို Terminal တွင် တစ်ချက် Run လိုက်ရုံဖြင့် သင့်စက်ရှိ After Effects Folder များထဲသို့ သက်ဆိုင်ရာနေရာအလိုက် အလိုအလျောက် ကူးယူပေးသွားမည်ဖြစ်ပါသည် -
```bash
bash "/Users/sithu/Desktop/After Effects plugin/install_to_ae.sh"
```

---

### နည်းလမ်း (၂) - မိမိကိုယ်တိုင် Manual ကူးယူထည့်သွင်းခြင်း

#### (က) Animation Presets များ ထည့်သွင်းရန် (`.ffx` ဖိုင်များ)
* **Mac:** 
  `Documents/Adobe/After Effects <Version>/User Presets/`
  *(User Presets ထဲသို့ `.ffx` ဖိုင်များပါသော Folder များကို ကူးထည့်လိုက်ပါက After Effects ၏ **Effects & Presets** Panel ထဲရှိ User Presets တွင် တိုက်ရိုက် ပေါ်လာပါမည်)*
* **Windows:**
  `Documents\Adobe\After Effects <Version>\User Presets\`

#### (ခ) Scripts နှင့် ScriptUI Panels များ ထည့်သွင်းရန် (`.jsx` ဖိုင်များ)
* **Mac:**
  `/Applications/Adobe After Effects <Version>/Scripts/ScriptUI Panels/`
  *(သို့မဟုတ် `~/Library/Application Support/Adobe/After Effects/<Version>/Scripts/`)*
* **Windows:**
  `C:\Program Files\Adobe\Adobe After Effects <Version>\Support Files\Scripts\ScriptUI Panels\`
* **အသုံးပြုပုံ:** After Effects ၏ အပေါ် Menu Bar မှ **Window -> [Script အမည်]** ကို နှိပ်၍ Panel အနေဖြင့် တိုက်ရိုက် ဖွင့်သုံးနိုင်ပါသည်။

#### (ဂ) Color Grading LUTs များ ထည့်သွင်းရန် (`.cube` ဖိုင်များ)
* **Mac:**
  `/Library/Application Support/Adobe/Common/LUTs/Creative/`
  *(အဆိုပါ Creative Folder ထဲသို့ `.cube` ဖိုင်များကို ထည့်ပါ)*
* **Windows:**
  `C:\Program Files\Adobe\Common\LUTs\Creative\`
* **အသုံးပြုပုံ:** After Effects ရှိ **Lumetri Color -> Creative -> Look** Dropdown တွင် အဆိုပါ ရုပ်ရှင်ဆန်သော LUT Look များကို ချက်ချင်း ရွေးချယ်နိုင်ပါပြီ (Premiere Pro တွင်လည်း တပြိုင်နက် သုံးနိုင်ပါသည်)။

DaVinci Resolve Plugins ထည့်သွင်းနည်း

Mac နှင့် Windows အတွက် အသုံးပြုနည်း အဆင့်ဆင့်

⚡ နည်းလမ်း (၁) - Mac အတွက် ၁ စက္ကန့်အတွင်း အလိုအလျောက် သွင်းခြင်း (Recommended)

Master Suite Folder ကို ဒေါင်းလုဒ်လုပ်ပြီး အထဲရှိ install_to_davinci.sh ဖိုင်ကို Terminal တွင် အောက်ပါ command ဖြင့် Run လိုက်ရုံဖြင့် DaVinci ၏ System Folder များထဲသို့ အလိုအလျောက် သွင်းပေးသွားပါမည် -

bash install_to_davinci.sh
⬇️ install_to_davinci.sh သီးသန့်ဒေါင်းမည်
နည်းလမ်း (၂) - Manual ကူးယူ ထည့်သွင်းနည်းလမ်းကြောင်းများ:
၁။ Text Animations (.setting ဖိုင်များ):
Mac: ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Templates/Edit/Titles
Win: %APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Templates\Edit\Titles
၂။ Visual Effect Plugins (.fuse ဖိုင်များ):
Mac: ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Fuses
Win: %APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses
၃။ Color DCTLs & LUTs (.dctl / .cube ဖိုင်များ):
DaVinci Resolve ဖွင့်ပါ → Project Settings (ဂီယာပုံ) → Color Management → Lookup Tables အောက်ရှိ Open LUT Folder ကိုနှိပ်၍ ကူးထည့်ပြီး Update Lists နှိပ်ပါ

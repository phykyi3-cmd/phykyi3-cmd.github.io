## 🌟 အဓိက အင်္ဂါရပ်များ (Key Features)

* **၁၇၂+ မူရင်း မြန်မာဖောင့်များ (True Type Fonts):**
  * 🎨 **Art House Series:** W01 မှ W70 အထိ ဂန္တဝင်အနုပညာစာလုံးထူ ဖောင့် ၆၈ မျိုး အပြည့်အစုံ
  * 💎 **Masterpiece & Round Series:** Uni Round, Cherry Pro, Choco Cooky, Sweetie စသော စာလုံးဝိုင်းလှလှများ
  * ✍️ **Aka & လက်ရေးလှဖောင့်များ:** Aka01 မှ Aka11 အထိ၊ Uni-Burmese Handwriting စီးရီးများနှင့် Tharlon
  * 📂 **Uni-Myanmar စုစည်းမှုများ:** ရုံးသုံး၊ စာစီစာရိုက်နှင့် ဒီဇိုင်းသုံး ခေတ်မီယူနီကုဒ်ဖောင့်များ
  * 🌟 **Unicode စံချိန်မီ & ရုံးသုံး:** Pyidaungsu, Myanmar3, Padauk, Noto Sans Myanmar
  * 🖨️ **Win Myanmar (ပုံနှိပ်ဖောင့်များ):** Win Innwa, Win Kalaw, Win Research ပုံနှိပ်ဖောင့်ဟောင်းများ
  * 📜 **Zawgyi & Legacy စုစည်းမှုများ**

* **⚡ Auto-Win Real-time Engine:**
  * Win Layout စနစ်သုံး Art House ဖောင့်များအတွက် မည်သည့် Unicode ကီးဘုတ်ဖြင့်မဆို စာရိုက်စမ်းသပ်နိုင်ပြီး မူရင်း Art House စာလုံးအလှအဖြစ် Box အကွက်များမဖြစ်ဘဲ အလိုအလျောက် ပြောင်းလဲပြသပေးပါသည်။

* **📱 Mobile & Laptop PWA Support:**
  * iPhone (Safari), Android (Chrome) နှင့် Laptop (Mac / Windows) များတွင် **"Add to Home Screen / Install App"** ဖြင့် Native Application ကဲ့သို့ ထည့်သွင်းအသုံးပြုနိုင်ပါသည်။

* **💡 Built-in Installation Guides:**
  * iPhone တွင် **iFont** အက်ပ်ဖြင့် System Font သွင်းနည်း
  * **CapCut iOS & Mobile** တွင် `.ttf` ဖောင့် တိုက်ရိုက် Import ပြုလုပ်နည်း
  * **PixelLab, InShot, Canva, zFont 3** အသုံးပြုနည်း
  * **Windows & Mac** 1-Click Installation
  * **Photoshop, Premiere Pro, Illustrator, CapCut PC** အသုံးပြုနည်း

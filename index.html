ဖုန်း & Laptop ဖောင့်ထည့်သွင်းနည်းလမ်းညွှန်

CapCut, PixelLab, iFont, Windows & Mac အသုံးပြုနည်းများ

🎬 CapCut iOS (iPhone) ထဲသို့ ဖောင့်တိုက်ရိုက်ထည့်နည်း

  1. Golden Fonts ဝက်ဘ်ဆိုက်မှ ဖောင့်ကို Download ဆွဲပါ (Safari ၏ Downloads ဖိုဒါထဲ ရောက်ရှိမည်)။
  2. CapCut အက်ပ်ကို ဖွင့်ပါ > Text > Add Text > Font ကို နှိပ်ပါ။
  3. Font မီနူးတွင် + (Add Font) ကို နှိပ်ပြီး ဖုန်းထဲမှ ဒေါင်းလုဒ်ဆွဲထားသော .ttf ဖိုင်ကို ရွေးပေးလိုက်ရုံဖြင့် ချက်ချင်း အသုံးပြုနိုင်ပါပြီ။

📱 iOS System (Settings) တစ်ခုလုံးသို့ ဖောင့်သွင်းနည်း (iFont App)

App Store မှ အခမဲ့ရရှိသော iFont အက်ပ်ကို ဒေါင်းလုဒ်ဆွဲပြီး Golden Fonts မှ ဒေါင်းလုဒ်ရရှိသော ဖောင့်ကို Open in iFont ဖြင့် ဖွင့်ကာ Install Profile ပြုလုပ်၍ iPhone စနစ်တစ်ခုလုံးတွင် သုံးနိုင်ပါသည်။

🎬 CapCut, PixelLab, InShot, Canva တွင် ဖောင့်ထည့်သွင်းနည်း

  1. Golden Fonts မှ ဖောင့်ကို ဒေါင်းလုဒ်ဆွဲပါ (ဖုန်း၏ Download ဖိုဒါထဲသို့ ရောက်ရှိသွားပါမည်)။
  2. CapCut Mobile တွင် Text > Font > + (Add Font) > ဖုန်းထဲမှ .ttf ဖိုင်ကို ရွေးပေးပါ။
  3. PixelLab တွင် Font > My Fonts > ဖိုဒါအိုင်ကွန် (+) ကို နှိပ်ပြီး Download ဖိုဒါထဲမှ ဖောင့်ကို ရွေးပါ။

🪟 Windows Laptop & PC

ဒေါင်းလုဒ်ရရှိသော .ttf ဖိုင်ပေါ်တွင် Right Click နှိပ်ပါ > Install for all users ကို နှိပ်ပါ။ Photoshop, Premiere Pro, CapCut PC ထဲတွင် ဖောင့်အမည်ဖြင့် ချက်ချင်းပေါ်လာပါမည်။

🍎 Apple Mac (MacBook / iMac)

ဒေါင်းလုဒ်ရရှိသော .ttf ဖိုင်ကို Double Click နှိပ်ပါ > ပွင့်လာသော Font Book ပေါ်တွင် Install Font ကို နှိပ်ပါ။

📲 Official App အဖြစ် Home Screen တွင် သွင်းယူနည်း (PWA)

  • Android (Chrome): ညာဘက်အပေါ်ရှိ မီနူး (⋮) ကို နှိပ်ပါ > "Install app (သို့) Add to Home screen" ကို ရွေးပါ။

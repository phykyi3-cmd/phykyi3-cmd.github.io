💡 ဖုန်းနှင့် Laptop တွင် ဖောင့်သွင်းနည်း လမ်းညွှန်

🍏 နည်းလမ်း ၁ - iFont အက်ပ်ဖြင့် iPhone စနစ်ထဲ ထည့်သွင်းနည်း (System-wide)

  1. Zee Motion ထဲမှ မိမိနှစ်သက်ရာဖောင့်ကို Free Download နှိပ်၍ ဒေါင်းလုဒ်ဆွဲပါ။
  2. App Store မှ အခမဲ့ရနိုင်သော iFont: find install any font အက်ပ်ကို ဒေါင်းလုဒ်ရယူပါ။
  3. ဒေါင်းထားသော `.ttf` ဖိုင်ကို ဖွင့်ပြီး Share > Open with iFont ကို ရွေးပါ။
  4. iFont အက်ပ်ထဲတွင် Install နှိပ်ပြီး Safari မှ Profile ဒေါင်းလုဒ်ကို Allow လုပ်ပေးပါ။
  5. iPhone ၏ Settings > Profile Downloaded > Install နှိပ်၍ Passcode ရိုက်ထည့်ကာ အတည်ပြုပါ။ Pages, Keynote, Canva နှင့် ဗီဒီယိုအက်ပ်များတွင် စနစ်ဖောင့်အဖြစ် အသုံးပြုနိုင်ပါပြီ။

🎬 နည်းလမ်း ၂ - CapCut iOS တွင် တိုက်ရိုက်ထည့်သွင်းနည်း

CapCut ဖွင့်ပါ > Text ထည့်ပါ > Font > Add Font (+) > Upload File ကို နှိပ်ပြီး ဒေါင်းလုဒ်ဆွဲထားသော `.ttf` ဖိုင်ကို ရွေးချယ်ပေးရုံဖြင့် ချက်ချင်း အသုံးပြုနိုင်ပါသည်။

🎬 CapCut, PixelLab, InShot, Canva တွင် ဖောင့်ထည့်သွင်းနည်း

  1. Zee Motion မှ ဖောင့်ကို ဒေါင်းလုဒ်ဆွဲပါ (ဖုန်း၏ `Download` ဖိုဒါထဲသို့ ရောက်ရှိသွားပါမည်)။
  2. CapCut Mobile တွင် Text > Font > + (Add Font) > ဖုန်းထဲမှ .ttf ဖိုင်ကို ရွေးပေးပါ။
  3. PixelLab တွင် Font > My Fonts > ဖိုဒါအိုင်ကွန် (+) ကို နှိပ်ပြီး `Download` ဖိုဒါထဲမှ ဖောင့်ကို ရွေးပါ။
  4. InShot တွင် Text > Font > အိတ်အိုင်ကွန် (Store) ဘေးရှိ Import (+) ကို နှိပ်ပြီး ထည့်သွင်းပါ။

📲 Samsung, Xiaomi, Oppo, Vivo စနစ်တစ်ခုလုံး ဖောင့်ပြောင်းနည်း

Play Store မှ zFont 3 အက်ပ်ကို အသုံးပြု၍ Zee Motion မှ ဒေါင်းလုဒ်ဆွဲထားသော ဖောင့်ကို System Font အဖြစ် လွယ်ကူစွာ သွင်းယူနိုင်ပါသည်။

🪟 Windows Laptop & PC (Windows 10 / 11)

ဒေါင်းလုဒ်ရရှိသော `.ttf` ဖိုင်ပေါ်တွင် Right Click နှိပ်ပါ > Install for all users (သို့မဟုတ် Install) ကို နှိပ်ရုံဖြင့် အလိုအလျောက် သွင်းပေးသွားပါမည်။

🍎 Apple Mac (MacBook, iMac, Mac mini)

ဒေါင်းလုဒ်ရရှိသော `.ttf` ဖိုင်ကို Double Click နှိပ်ပါ > ပွင့်လာသော Font Book ပေါ်တွင် Install Font ကို နှိပ်ပါ။

🎨 Photoshop, Premiere Pro, After Effects, CapCut PC

ကွန်ပျူတာထဲ ဖောင့်သွင်းပြီးပါက သက်ဆိုင်ရာ Software ကို ပိတ်ပြီး ပြန်ဖွင့်ရုံဖြင့် Font Selector ထဲတွင် ဖောင့်အမည်ဖြင့် တိုက်ရိုက်ရိုက်ထည့် အသုံးပြုနိုင်ပါသည်။

📲 Official App အဖြစ် Home Screen တွင် သွင်းယူနည်း (PWA)

  • 🍎
    iPhone (Safari): မျက်နှာပြင်အောက်ခြေရှိ Share (⎋) အိုင်ကွန်ကို နှိပ်ပါ > အောက်သို့ဆွဲပြီး "Add to Home Screen (ပင်မစာမျက်နှာသို့ ထည့်ပါ ⊕)" ကို နှိပ်ပါ။
  • 🤖
    Android (Chrome): ညာဘက်အပေါ်ရှိ မီနူး (⋮) ကို နှိပ်ပါ > "Install app (သို့) Add to Home screen" ကို ရွေးပါ။
  • 💻
    Laptop (Chrome / Edge): Address Bar ၏ ညာဘက်စွန်းရှိ Install Icon (⊕) ကို နှိပ်၍ သီးခြား App Window အဖြစ် တပ်ဆင်နိုင်ပါသည်။
